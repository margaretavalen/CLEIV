# Clean Living (CLEIV) Project Using HTML, CSS and Javascript 👔

This is the CLEIV web application, a platform designed to make it easier for users to order laundry services online. 
With a user-friendly interface, users can easily schedule laundry services without having to physically go to the laundry place.
